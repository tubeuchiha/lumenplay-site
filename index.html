功能一览

为 4K 而生的播放内核

不依赖系统播放器，画面调度更精细：拖动进度条指哪打哪，长片不卡不飘。

HDR / 杜比视界

HDR10 / HLG 元数据透传；杜比视界与 Atmos 在支持的设备上自动启用专用通路。

原码直通

硬件设备满足条件下，LumenPlay 支持将杜比系 / DTS 系音频原始码流输出至功放解码，无损音轨原样送达。

自建媒体库直连

Jellyfin / WebDAV / SMB（Windows 共享 / NAS）开箱即连，密码本机加密存储。

网络播放更稳

自适应码率（ABR）：网络波动时自动调整清晰度，看片不断流；断网恢复后自动续上。

大文件与高码率

>4GB 原盘文件全量支持；网络出状况也能接着看，不从头再来。

字幕全格式

SRT / ASS / SSA / PGS / TTML，外挂字幕自动匹配、多轨切换、独立延迟调节。
