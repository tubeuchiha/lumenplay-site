Features

A playback core built for 4K

No reliance on the system player, so frame scheduling is far more precise: seeking lands exactly where you point, and long 4K films stay smooth when bandwidth and hardware allow.

HDR / Dolby Vision

HDR10 / HLG metadata is passed through. Dolby Vision and Atmos require device support: supported devices use the dedicated path automatically, unsupported devices play the HDR10 base layer — no washed-out or tinted picture.

Bitstream passthrough

Where both the device and the AV receiver support it, LumenPlay sends the original Dolby / DTS bitstream to the receiver for decoding, with no decode-and-re-encode step. If either end lacks support, the track is decoded to PCM and the film plays as usual.

ISO / BDMV disc playback

Open a Blu-ray ISO image or BDMV folder structure directly (local storage or an SMB share). The main feature is located and played automatically — no unpacking, no third-party tools.

ASS / SSA styled subtitles

Embedded ASS / SSA subtitles render as authored: positioning, fonts, colours, outlines and shadows, fades, karaoke timing and CJK line breaking are all preserved, crisp on a 4K picture. SRT / PGS / TTML and other formats are available in every edition.

Automatic frame-rate matching (free)

At playback start the display refresh rate is switched to match the source (a 23.976 fps film plays at 23.976 Hz), so camera pans stop juddering. If the device has no matching mode, nothing changes. Free and on by default.

Self-hosted libraries

Jellyfin and Emby both supported natively; WebDAV and SMB (Windows shares / NAS) work out of the box. Credentials are encrypted on the device.

Steadier network playback

Adaptive bitrate (ABR): when playing HLS / DASH streams (.m3u8 / .mpd) quality is switched to match bandwidth, reducing stalls and buffering.

Large files, high bitrates

MKV / MP4 files beyond 4 GB and high-bitrate titles play reliably. Transient network drops are retried automatically and playback resumes; if you stop for longer, reopening returns you to where you left off.

Many subtitle formats

SRT / ASS / SSA / PGS / TTML, with automatic external-subtitle matching, track switching and independent delay adjustment.

Jellyfin / Emby, one client for both: enter the server address on the same sign-in screen and your library, continue-watching, resume points, audio tracks and subtitles all work. Files the client can decode play directly without server transcoding; anything it cannot decode (for example some AV1 sources) is transcoded by the server and still plays. All network sources, including WebDAV and SMB, are free — Emby and Jellyfin users do not need a second paid client.

Pricing & support

LumenPlay is a one-time purchase with lifetime use: no ads, no subscription, no data collection. Local playback and all network sources (Jellyfin / Emby / WebDAV / SMB) are free, as is automatic frame-rate matching. What the purchase unlocks is audio and picture capability: TrueHD / DTS-HD bitstream passthrough (where device and receiver both support it), ISO / BDMV disc playback and ASS / SSA styled subtitles. A 7-day full-feature trial starts the first time you use any of those paid capabilities (for example the first Dolby / DTS title you play, or the first disc or styled subtitle). All three work during the trial — no sign-up, no account. When it ends the App returns to the free set: lossless tracks are decoded to PCM and the film still plays in full.
