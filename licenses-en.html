Open-source licences

LumenPlay is distributed as closed-source software. Below are the open-source components it uses and how their licence obligations are met.

FFmpeg — LGPL-2.1 or later

The app uses FFmpeg (version 7.1.5, unmodified upstream sources) for media demuxing, dynamically linked as separate shared libraries (libavformat.so / libavcodec.so / libavutil.so / libswresample.so). It is not statically linked and no GPL or non-free components are enabled.

  • Source: ffmpeg.org/download.html (unmodified upstream)
  • Full licence: LGPL-2.1
  • Relinking: the .so files above are standard ELF shared objects; you may replace them with your own builds of the same name to relink.

Build configuration (configure summary)

--enable-cross-compile --enable-pic
--enable-static --disable-shared --disable-symver
--disable-programs --disable-doc --disable-avdevice
--disable-swscale --disable-swresample --disable-avfilter --disable-postproc
--disable-encoders --disable-decoders --disable-muxers
--disable-filters --disable-devices
--enable-network --enable-openssl --enable-libxml2
--enable-demuxer=<allowlist> --enable-protocol=<allowlist>
--enable-parser=<allowlist> --enable-bsf=<allowlist>
--enable-decoder=<subtitle/audio decoder allowlist> --enable-small

The complete build script build_ffmpeg.sh is available on request by email.
