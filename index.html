功能一览

自研播放内核

基于 FFmpeg 自建解封装、解码与音视频同步管线，不依赖系统播放器：seek 直接定位目标帧，画面调度与缓冲策略自主可控，4K 高码率长片全程稳定流畅。

HDR / 杜比视界

HDR10 / HLG 元数据透传，普通屏幕自动色调映射。杜比视界与 Atmos 需要设备本身支持：支持的设备上自动启用专用通路；含 HDR10 兼容层的片源（Profile 8）在不支持的设备上按基础层播放。Profile 5 没有兼容图层，设备不支持杜比视界时由播放器映射为 SDR 画面播放，不出现偏色花屏。

音频原码直通

在设备与功放同时支持的条件下，将杜比系 / DTS 系音频的原始码流不经解码直接输出至功放，保留录音室级动态范围与声道布局；任一环节不支持该编码时，自动回退为 PCM 解码输出，播放不中断。

原盘 ISO / BDMV 播放

直接读取蓝光原盘 ISO 镜像与 BDMV 目录结构（本地存储或 SMB 共享），解析 PLAYLIST 自动定位正片，无需解包、无需第三方工具。

专业字幕渲染引擎

内置 libass 渲染管线，ASS / SSA 特效字幕按作者意图逐项还原：绝对定位、字体样式、描边阴影、淡入淡出、卡拉OK 逐字上色与 CJK 智能换行，4K 分辨率下清晰锐利。另支持 SRT / PGS / TTML 等格式：外挂字幕自动匹配、多轨切换、独立延迟调节。

自动帧率匹配

起播时将显示设备刷新率切换至与片源帧率一致（如 23.976 fps → 23.976 Hz），消除运动画面的规律性抖动（judder）；设备无对应档位时保持原状，不影响播放。

自建媒体库直连

  • Jellyfin / Emby 双协议原生直连——媒体库浏览、继续观看、断点同步、多音轨与字幕切换，两款服务器共用同一登录入口。
  • 智能直连（Direct Play）——客户端能解码的文件直接播放，不经服务器转码；解不了的编码（如部分 AV1 片源）由服务器转码兜底，不会黑屏。
  • WebDAV / SMB 开箱即连——Windows 共享与 NAS 直接添加，凭据加密后仅存本机，不上传服务器。
  • 全部网络源免费使用——Emby / Jellyfin 用户不必再为第二个播放客户端付费。

网络播放更稳

自适应码率（ABR）：播放 HLS / DASH 自适应流（.m3u8 / .mpd）时按实时带宽动态切换清晰度，配合多级缓冲策略降低卡顿与重缓冲次数。

大文件与高码率

支持超过 4GB 的 MKV / MP4 大文件与高码率影片稳定播放；网络闪断自动重试、断点续播，长时间中断后重新打开即恢复至上次进度。
