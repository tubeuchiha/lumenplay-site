功能一览

为 4K 而生的播放内核

不依赖系统播放器，画面调度更精细：拖动进度条指哪打哪；带宽与硬件允许的前提下，4K 长片流畅稳定。

HDR / 杜比视界

HDR10 / HLG 元数据透传，普通屏幕自动色调映射。杜比视界与 Atmos 需要设备本身支持：支持的设备上自动启用专用通路；含 HDR10 兼容层的片源（Profile 8）在不支持的设备上按基础层播放。Profile 5 没有兼容底层，设备不支持杜比视界时会偏色——播放器会明确提示，不冒充正常画面。

原码直通

在设备与功放同时支持的条件下，LumenPlay 将杜比系 / DTS 系音频的原始码流输出至功放解码，不经过解码转码。设备或功放不支持该编码时，音轨自动解码为 PCM 输出，影片照常播放。

原盘 ISO / BDMV 播放

直接打开蓝光原盘的 ISO 镜像或 BDMV 目录结构（本地存储或 SMB 共享），自动定位正片开始播放，无需先解包、无需第三方工具。

ASS / SSA 特效字幕

内嵌 ASS / SSA 字幕按原样渲染：定位、字体样式与颜色、描边阴影、淡入淡出、卡拉OK 逐字上色、CJK 长句自动换行完整还原，4K 画面下清晰锐利。SRT / PGS / TTML 等其余字幕格式全版本可用。

自动帧率匹配（免费）

起播时把电视 / 显示器刷新率切换到与片源一致（如 23.976 帧的片源 → 23.976Hz），横移镜头不再一顿一顿。设备没有对应档位时静默不变，不打扰。免费提供，默认开启。

自建媒体库直连

Jellyfin / Emby 双协议直连，WebDAV / SMB（Windows 共享 / NAS）开箱即连，密码本机加密存储。

网络播放更稳

自适应码率（ABR）：播放 HLS / DASH 自适应流（.m3u8 / .mpd）时按带宽自动切换清晰度，减少卡顿与缓冲。

大文件与高码率

支持超过 4GB 的 MKV / MP4 大文件与高码率影片稳定播放；网络闪断时自动重试，恢复后接着播；中断较久也不怕，重新打开会回到上次进度。

支持多种格式字幕

SRT / ASS / SSA / PGS / TTML，外挂字幕自动匹配、多轨切换、独立延迟调节。

Jellyfin / Emby 双协议直连：两款主流家庭媒体服务器一套客户端全搞定—— 同一个登录页填服务器地址即可，媒体库、继续观看、断点同步、多音轨字幕均可用。 客户端能解码的文件直接播放，不经过服务器转码；遇到客户端解不了的编码（例如部分 AV1 片源）， 由服务器转码后再播，不会黑屏。全部网络源（含 WebDAV / SMB）免费使用， Emby / Jellyfin 用户不必再为第二个播放客户端付费。
