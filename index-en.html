Features

Custom playback core

A demux, decode and A/V sync pipeline built on FFmpeg, independent of the system player: seeks land on the target frame, scheduling and buffering are fully under our control, and long 4K high-bitrate titles play smoothly end to end.

HDR / Dolby Vision

HDR10 / HLG metadata is passed through, with automatic tone mapping on regular displays. Dolby Vision and Atmos require device support: supported devices use the dedicated path automatically; sources with an HDR10-compatible base layer (Profile 8) fall back to it on unsupported devices. Profile 5 has no base layer — on devices without Dolby Vision, the player maps it to SDR playback so the picture does not break.

Audio bitstream passthrough

Where both the device and the AV receiver support it, the original Dolby / DTS bitstream is sent to the receiver undecoded, preserving studio dynamic range and channel layout. If any link lacks support, output falls back to PCM decoding without interrupting playback.

ISO / BDMV disc playback

Reads Blu-ray ISO images and BDMV folder structures directly (local storage or SMB share), parses PLAYLIST entries to locate the main feature — no unpacking, no third-party tools.

Professional subtitle rendering

A libass-based pipeline renders ASS / SSA subtitles exactly as authored: absolute positioning, font styling, outlines and shadows, fades, karaoke timing and CJK line breaking, crisp at 4K. SRT / PGS / TTML and other formats are also supported, with automatic external-subtitle matching, track switching and independent delay adjustment.

Automatic frame-rate matching

At playback start the display refresh rate is switched to match the source (23.976 fps → 23.976 Hz), removing rhythmic motion judder. If the device has no matching mode, playback continues unchanged.

Self-hosted libraries

  • Native Jellyfin & Emby clients — library browsing, continue watching, resume sync and audio / subtitle track switching; both servers share one sign-in screen.
  • Direct Play — files the client can decode play directly without server transcoding; anything it cannot (e.g. some AV1 sources) falls back to server transcoding, no black screens.
  • WebDAV / SMB out of the box — Windows shares and NAS connect directly; credentials are encrypted and stored on the device only.
  • All network sources free — Emby / Jellyfin users never pay for a second playback client.

Steadier network playback

Adaptive bitrate (ABR): when playing HLS / DASH streams (.m3u8 / .mpd), quality is switched dynamically to match available bandwidth, with multi-level buffering to reduce stalls and rebuffering.

Large files, high bitrates

MKV / MP4 files beyond 4 GB and high-bitrate titles play reliably. Transient network drops are retried automatically with seamless resume; after longer interruptions, reopening returns to the last playback position.
