Get activation codes

Enter your order ID and device machine codes — codes are generated instantly and emailed to you. Only the activation code needs to be pasted into the app; machine codes are just labels for telling devices apart.

Notes

  1. Each device uses one activation code bound to its machine code. Enter it in the app's Playback settings → Unlock full version.
  2. Up to 3 devices per order. Requesting a code for an already-issued machine re-sends the same code without using your replacement quota.
  3. For a replacement device (old one no longer in use), contact support@lumenplay.app with your original order ID to release the old device, then enter the original order ID plus the new machine code here. Maximum 3 devices per order — if full, please contact support first.
  4. Codes are also emailed to your purchase address — keep that email. Refund policy · Terms.
